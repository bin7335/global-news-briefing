# 글로벌 뉴스 브리핑 스킬

사용자가 "오늘 경제 시황 어때?", "글로벌 동향 브리핑 해줘" 등 매크로 시황과 관련된 요청을 할 때 이 스킬을 활용하세요.

## 실행 절차 (Execution Steps)

1. 아래의 GitHub Raw URL을 읽으세요 (브라우저나 HTTP Fetch 도구 활용):
   `https://raw.githubusercontent.com/bin7335/global-news-briefing/main/news-summary-result.md`

2. 위 URL에는 매일 갱신되는 마크다운 포맷의 깔끔한 글로벌 경제 시황 요약본이 들어있습니다.

3. 문서를 읽어온 후, 사용자에게 핵심 내용(거시/환율, 증시 반응, AI/반도체 동향 등)을 요약해서 브리핑해 주거나 사용자의 질문에 답하세요.

> **Note**: 유튜브에서 직접 정보를 찾을 필요가 없습니다. 저 주소에 봇 차단을 우회하여 매일 아침 추출된 최신 뉴스 요약이 항상 준비되어 있습니다!
